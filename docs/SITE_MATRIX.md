# MendoSave - проверенная совместимость

Проверки версии 0.2.0: 09-10-2026. Основная среда - Zen 1.23.1b / Gecko 157.0.1 на Windows; дополнительная сборка - Chromium 148.0.7778.96. Использованы отдельные профили без авторизации. Воспроизведение заглушено, аудиодорожки файлов сохранены.

Матрица относится к указанным материалам и сценариям. Unit tests проверяют контракты адаптеров, но не доказывают доступность площадки. `Файл проверен` означает проверку контейнера, дорожек, длительности, полного декодирования и начальных/конечных кадров либо аудиосэмплов. Состояние фазы и подробные ограничения - в [ROADMAP.md](ROADMAP.md) и [PHASE2_VERIFICATION.md](PHASE2_VERIFICATION.md).

## Отдельные режимы

Live, очередь материалов плейлиста и пакет форматов - разные сценарии. Завершённый VOD не доказывает запись rolling HLS. Rutube/Twitch VOD отвергают шифрование, незавершённый playlist и неподдержанные `EXT-X-MAP` / `BYTERANGE`, вместо сохранения неполного файла.

На [Rutube playlist](https://rutube.ru/plst/849646/) проверена страница списка: активного video и кнопки загрузки нет. Сохранение всей подборки не реализовано. Унаследованная YouTube playlist queue сохраняется в коде; сквозной проход нескольких материалов и восстановление такой очереди в фазе 2 не подтверждены и не включены в перечень проверенных возможностей.

Пакет выбранных форматов, ZIP и единый Save As для всех адаптеров относятся к фазе 3. Page-Blob пути Coub/Twitch live/Zvuk пока сохраняются отдельно от processor path; общий переключатель места сохранения ещё не подключён к каждому из них. Twitch live накапливает MediaRecorder chunks в памяти; короткая проверка не устанавливает границу долгого эфира.

Musify отключён и исключён из обеих сборок. Instagram, другие ОС, другие Firefox-производные, произвольные версии Zen и весь каталог каждой площадки не подтверждены.
