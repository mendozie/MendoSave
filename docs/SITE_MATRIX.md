## Отдельные режимы

Live, очередь материалов плейлиста и пакет форматов - разные сценарии. Завершённый VOD не доказывает запись rolling HLS. Rutube/Twitch VOD отвергают шифрование, незавершённый playlist и неподдержанные `EXT-X-MAP` / `BYTERANGE`, вместо сохранения неполного файла.

На [Rutube playlist](https://rutube.ru/plst/849646/) проверена страница списка: активного video и кнопки загрузки нет. Сохранение всей подборки не реализовано. Унаследованная YouTube playlist queue сохраняется в коде; сквозной проход нескольких материалов и восстановление такой очереди в фазе 2 не подтверждены и не включены в перечень проверенных возможностей.

В 0.3.0 подключён общий Save As для processor и Page-Blob путей, включая Coub/Звук. Пакеты форматов добавлены к адаптерам, где есть несколько конечных вариантов; Звук не показывает искусственный пакет при единственной доступной аудиопозиции. Regression fixtures покрывают adapter/package seams; полная новая live-проверка пакета на каждой площадке не выполнена. Twitch live передаёт MediaRecorder chunks в OPFS обработчика и завершает WebM локально; закрытие исходной вкладки сохраняет полученный фрагмент. Короткие проверки не устанавливают предел долгого эфира и не доказывают восстановление после закрытия браузера.
