# Установка, обновление и удаление

## Версии для проверки

Локальный тестовый кандидат 0.3.2 находится в `artifacts/mendosave-0.3.2/`: unsigned XPI, Chromium ZIP, matching source, `release-manifest.json` и `SHA256SUMS`. [Инструкция установки кандидата](V032_VERIFICATION.md#ручная-установка-кандидата) описывает отдельный тестовый профиль и фактические ограничения. Опубликованная подписанная версия - 0.3.1; 0.3.2 не подписана и не опубликована.

Основная проверенная среда - Zen на Windows; точные версии и сценарии находятся в [SITE_MATRIX](SITE_MATRIX.md). Chromium - дополнительная сборка из общего кода. Совместимость других браузеров и ОС не подтверждается совпадением движка.

Готовые пакеты находятся в [Release 0.3.1](https://github.com/mendozie/MendoSave/releases/tag/v0.3.1). Репозиторий приватный, поэтому для скачивания нужен доступ к нему. Сверь SHA-256 скачанного файла с `SIGNED_SHA256SUMS` из того же Release.

До подписания Firefox/Zen candidate устанавливается временно только в отдельный тестовый профиль через `about:debugging` → This Firefox → Load Temporary Add-on → `dist/firefox/manifest.json`. Установка исчезает после полного перезапуска браузера; это свойство временной установки. Не отключай signature checks рабочего профиля. [Описание Mozilla](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/).

Для Chromium распакуй `mendosave-0.3.1-chromium-unsigned.zip` в постоянную папку. Открой `chrome://extensions`, включи developer mode, выбери «Загрузить распакованное расширение» и распакованную папку с `manifest.json`. Проверки выполнялись в отдельном профиле Chromium 148.0.7778.96 на Windows. Для developer-сборки из исходников используй `dist/chromium`.

## Подписанный файл для Firefox / Zen

Mozilla подписала MendoSave 0.3.1 как unlisted, без страницы в магазине. Для установки предназначен `mendosave-0.3.1-firefox-signed.xpi`; файл с суффиксом `unsigned` предназначен для разработки. Фактическая проверка подписи, обновления, перезапуска и конечного файла находится в [отчёте 0.3.1](SIGNING_VERIFICATION_031.md). [Проверка 0.3.0](SIGNING_VERIFICATION.md) сохранена как исторический baseline.

Сверь имя и SHA-256 с `SIGNED_SHA256SUMS` рядом с файлом. В Zen открой `about:addons` → меню с шестерёнкой → «Установить дополнение из файла…» (Install Add-on From File) и выбери подписанный XPI. Прочитай разрешения и подтверди установку. Проверка выполнена в отдельном профиле Zen 1.23.2b / Gecko 157.0.1 на Windows 11: расширение установлено постоянно, подпись обязательна и принята, после полного перезапуска расширение активно. Рабочий профиль пользователя при проверке не менялся. Манифест требует Gecko 157.0 или новее; другие версии отдельно не проверены.

Для unlisted обновления устанавливаются вручную; собственного update manifest сейчас нет. Публикация в магазине сейчас не планируется. [Различия каналов](DISTRIBUTION.md).

## Обновление

Дождись завершения jobs или отмени их. Сначала сохрани необходимые recovery inputs через popup: OPFS является временным хранилищем, а автоматического продолжения активного job после restart нет.

Для временной Zen-сборки пересобери проект и нажми Reload в `about:debugging`; после полного restart установи временную сборку снова. Для Chromium замени содержимое прежней папки установки новой распакованной сборкой, нажми Reload на карточке расширения в `chrome://extensions`, затем обнови страницы с его controls. Сохраняй прежнюю папку установки, чтобы не создавать отдельную developer identity. Активные jobs при reload могут прерваться.

Для подписанного обновления снова выбери новый подписанный XPI через «Установить дополнение из файла…». Сохраняется ID `mendosave@mendozie`. В отдельном Zen-профиле обновление 0.3.0 → 0.3.1 сохранило настройки и UUID; подпись принята, постоянная установка активна после полного restart. Переход с прежнего `mendosave-dev@mendozie.local` является новой установкой; сохранение OPFS/настроек между identity не обещается. До перехода выгрузи нужные файлы. Рабочие cookies и пользовательские расширения для этого менять не требуется.

## Удаление

Сначала останови jobs и выгрузи recovery files. Удали MendoSave через `about:addons` в Zen либо `chrome://extensions` в Chromium. Настройки и временные данные расширения могут быть потеряны; скачанные пользователем файлы остаются в выбранной папке. Их удаление выполняется пользователем отдельно.

Локальная developer-папка не является установкой отдельной программы обработки. Удалять её или тестовый профиль для обычного отключения расширения не требуется. Для хранения данных и журналов см. [PRIVACY](../PRIVACY.md).
