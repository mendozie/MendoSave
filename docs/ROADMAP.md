## Текущее состояние

- Текущий результат: фаза 1 технически проверена; локальная версия 0.1.0 на branch `feat/zen-media-path`.
- Выполнено: перед импортом сверены все 41 файла upstream по Git blob hashes; импортирована рабочая папка `extension/` с сохранённым эталоном. Собраны Firefox/Chromium manifests и независимый от popup processor. В Zen сохранены контрольное видео YouTube 240p, MP3 и настоящие SRT, прямой HTTPS-файл и минутный файл через WASM. Исправлены ложные DOM-субтитры, потеря выбранного кодека в SABR и подмена AAC на Opus. Совпадение исходных дорожек с Chromium подтверждено хешами.
- Проверки: 23 автоматических regression tests; реальные decode/frame/audio/caption checks; отмена, повреждённый вход, закрытие host и повторная загрузка, скрытый и закрытый инициатор, OPFS recovery, wide/narrow screenshots и клавиатура. Полная запись и ограничения - в [PHASE1_VERIFICATION.md](PHASE1_VERIFICATION.md).
- Пользовательская приёмка: подготовка и направление приняты 09-10-2026. Технический срез готов к просмотру; визуальная приёмка пользователем не заявляется автоматически.
- Публикация: GitHub remote, релиз и отправка в Mozilla отсутствуют. Текущее поручение запрещает внешнюю публикацию; репозиторий остаётся локальным и приватным до релизной версии.
- Следующий результат: фаза 2 - собственное оформление и проверенная матрица адаптеров. Текущее поручение относится к фазе 1; фаза 2 ещё не начата и не расширяется этим отчётом.
- Подтверждённая совместимость: Zen 1.23.1b / Gecko 157.0.1 на Windows и контрольная Chromium-сборка в Chrome 148.0.7778.96. Другие версии, сайты, live и playlists пока не подтверждены.

## Фаза 1 - первый рабочий путь в Zen

Статус: `[x]`; технический результат проверен 09-10-2026; внешняя публикация запрещена.

Результат: загрузка контролируемого видео/аудио/субтитров в Zen с работающим browser-specific host медиапроцессора, без заявления о готовности всех площадок.

- [x] Импортировать проверенную исходную базу в рабочее дерево с сохранёнными лицензиями. Legacy build/CI не запускались; updater отключён.
- [x] Получить Chromium baseline и полный путь для YouTube watch: UI → metadata/media → processor → конечный файл.
- [x] Подготовить Firefox manifest и browser adapter; проверить MAIN/ISOLATED bridge, WASM workers, OPFS, Blob URLs и завершение downloads.
- [x] Проверить независимость от документа popup, скрытый и закрытый инициатор, минутный WASM job, abort и повторный запуск после закрытия host; выбрать закреплённую вкладку расширения для Zen.
- [x] Внести контрактные исправления с regression checks, проверить совокупный diff по `$code-review` и локальный состав сборки.

Evidence: A-001/A-002 для контрольного материала подтверждены. A-006/A-008/A-009 покрыты частично указанными сценариями; полный browser restart, квоты, все адаптеры, UX отмены и релизная безопасность остаются в следующих этапах. См. [отчёт](PHASE1_VERIFICATION.md).

После разрешения реализации продолжать принятый срез самостоятельно; не вводить gate после каждого теста. Существенный новый подход вне spec требует решения пользователя.

## Фаза 2 - самостоятельное расширение и совместимость адаптеров

Статус: `[ ]`.

Результат: MendoSave в собственном оформлении, общий код для двух сборок и проверенная матрица поддерживаемых сайтов.

- Убрать пользовательские ссылки/обновления upstream; заменить имя, namespace и диагностические подписи по необходимости. Сохранить происхождение и notices.
- Проверить YouTube watch/Music/Shorts, Rutube, VK, TikTok, Twitch, Coub и Звук по реально существующим возможностям. Live и playlist checks вести отдельно от одиночного VOD.
- Провести Chromium regression для изменённой общей логики. Отдельно обработать несовпадение Chrome offscreen/storage и разные пути сохранения.

Evidence: A-003/A-006/A-007/A-008 в относящейся к фазе части; для неподдержанных сценариев - честный статус и причина, без молчаливого исключения из исходного объёма.

## Фаза 3 - выбор места и пакеты

Статус: `[ ]`.

Результат: удобная одиночная загрузка, выбор нескольких форматов, последовательные отдельные файлы и ZIP.

- Подключить R-004 ко всем путям сохранения и проверить отмену штатного диалога.
- Добавить выбранные позиции пакета и последовательную очередь, сохранив одиночное скачивание и различие с playlist queue.
- Выбрать и проверить локальную ZIP library; реализовать упаковку без изменения bytes медиа и с контролем ресурсов/частичных результатов.
- Проверить progress, error/cancel/recovery и несколько вкладок; провести visual и keyboard QA.

Evidence: A-003/A-004/A-005/A-006/A-009; завершённые файлы и архивы, TDD/regression evidence, размеры viewport и code review. Большие ZIP и квоты имеют измеренную границу, а не обещание бесконечного размера.

## Фаза 4 - публичный выпуск

Статус: `[ ]`; внешние действия требуют применимого разрешения.

Результат: проверенный подписанный пакет и публичные материалы с фактическими возможностями, ограничениями и правилами приватности.

- Проверить зависимости, локальные версии, состав пакета, source/build reproducibility и лицензионную поставку.
- Выполнить применимые тесты, `web-ext` lint/build, code review и `$codex-security:security-scan`; разобрать существенные findings.
- Подготовить инструкции установки, privacy/security reporting и поддерживаемую матрицу. Выбрать add-on ID и канал AMO/unlisted.
- До релизной версии сохранять приватность репозитория. После применимого разрешения открыть репозиторий и выполнить подписанный выпуск; проверить сохранённые внешние условия и доступность пакета через readback.

Evidence: A-008/A-010, подтверждённое подписание/установка и readback разрешённой публикации. Наличие public GitHub source не означает подписанный или одобренный Mozilla пакет.

## Последующее исследование

Instagram Reels, другие Firefox-производные, другие ОС и дополнительные UX-функции рассматриваются после основной совместимости. Возможность сохранить внешнюю папку между пакетами без диалогов потребовала бы другого подхода; Native Messaging сейчас не выбран.
