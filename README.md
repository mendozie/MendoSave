# MendoSave

Расширение для локального сохранения видео, аудио и субтитров. Основная целевая среда - Zen Browser на Windows. Проект развивается на основе Nova Video Saver; условия исходника и библиотек сохранены в [LICENSE](LICENSE) и [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Фаза 1 технически проверена 09-10-2026: в отдельном профиле Zen 1.23.1b на Windows сохраняются контрольное видео YouTube, MP3 и SRT. Chromium-сборка проверена на том же материале. Это локальная разрабатываемая версия 0.1.0; другие адаптеры, пакеты и подписанный выпуск ещё предстоит проверить. Подробные результаты находятся в [отчёте фазы 1](docs/PHASE1_VERIFICATION.md), ближайший этап - в [roadmap](docs/ROADMAP.md#текущее-состояние).

## Локальная сборка и проверка

Нужен Node.js 22 или новее. Из корня репозитория в PowerShell:

```powershell
npm.cmd install --ignore-scripts --no-audit --no-fund
npm.cmd test
npm.cmd run build
npm.cmd run lint:extension
npx.cmd web-ext build --source-dir dist/firefox --artifacts-dir .local/qa/packages --filename mendosave-0.1.0-firefox-final.zip
```

Сборка создаёт `dist/firefox` и `dist/chromium` из общего исходника. Для загрузки используй manifest из соответствующей папки `dist`, поскольку `extension/manifest.json` - вход сборки. Списки файлов с SHA-256 находятся в `dist/firefox-hashes.json` и `dist/chromium-hashes.json`. Локальный ZIP не подписан.

Для проверки создай отдельный профиль Zen, открой в нём `about:debugging`, выбери «This Firefox» → «Load Temporary Add-on» и укажи `dist/firefox/manifest.json` либо локальный ZIP. Временная установка действует до перезапуска браузера; это [режим разработки Mozilla](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/). Не меняй настройки подписей и рабочий профиль.

На странице YouTube watch открой кнопку MendoSave в плеере; на узком экране она находится под плеером. В проверенном случае доступны видео 240p, MP3 и английские SRT. «Оригинал» сохраняет исходные кодеки, а «MP4 (H.264/AAC)» перекодирует при необходимости. MP3 использует VBR V0, его битрейт зависит от материала. Файлы пока поступают в каталог загрузок браузера.

В Zen обработчик работает в отдельной закреплённой вкладке MendoSave. Сохраняй её открытой до окончания обработки; popup можно закрыть. Если обработчик закрыт, текущая обработка прекращается, а повторная загрузка открывает новый. Автоматическое продолжение прерванного задания пока не реализовано.

`lint:extension` сейчас сообщает два предупреждения внутри неизменённого FFmpeg bundle. Строгая проверка `lint:extension:strict` и пригодность к подписанному выпуску остаются отдельными задачами перед релизом.

## Продолжение в Codex

Добавь или выбери локальную папку этого репозитория как проект и открой в ней чат. На этой машине папка называется MendoSave; точный путь сохранён в локальном файле `.local/PROJECT_LOCATION.md`. Для любого клона абсолютный путь можно получить из его корня:

```powershell
git rev-parse --show-toplevel
```

Первое сообщение для продолжения:

```text
Продолжим MendoSave. Прочитай AGENTS.md, docs/PROJECT_SPEC.md и текущее состояние docs/ROADMAP.md. Восстанови принятые решения, проверки и границы разрешённой работы. Назови ближайший шаг и выполни его, если он уже разрешён; если требуется новое разрешение, покажи конкретный план этого шага. Не повторяй подготовку проекта.
```

Неизменённый исходник доступен локально в `.local/upstream/source/`; происхождение и контрольные суммы находятся в `.local/upstream/SOURCE.json`. Эта копия остаётся эталоном и не входит в Git. Рабочая копия импортирована в `extension/`; исторический README сохранён в [docs/upstream/README.md](docs/upstream/README.md). Исходник также доступен по закреплённой ссылке из [аудита](docs/SOURCE_AUDIT.md#исходная-база).
