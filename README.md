# MendoSave

Расширение для локального сохранения видео, аудио и субтитров. Основная целевая среда - Zen Browser на Windows. Проект развивается на основе Nova Video Saver; условия исходника и библиотек сохранены в [LICENSE](LICENSE) и [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Проект находится на этапе подготовки. Рабочая версия MendoSave и подтверждённая совместимость с Firefox пока отсутствуют. Статус разработки и ближайшее действие находятся в [roadmap](docs/ROADMAP.md#текущее-состояние).

## Продолжение в Codex

Добавь или выбери локальную папку этого репозитория как проект и открой в ней чат. На этой машине папка называется MendoSave; точный путь сохранён в локальном файле `.local/PROJECT_LOCATION.md`. Для любого клона абсолютный путь можно получить из его корня:

```powershell
git rev-parse --show-toplevel
```

Первое сообщение для продолжения:

```text
Продолжим MendoSave. Прочитай AGENTS.md, docs/PROJECT_SPEC.md и текущее состояние docs/ROADMAP.md. Восстанови принятые решения, проверки и границы разрешённой работы. Назови ближайший шаг и выполни его, если он уже разрешён; если требуется новое разрешение, покажи конкретный план этого шага. Не повторяй подготовку проекта.
```

Неизменённый исходник доступен локально в `.local/upstream/source/`; происхождение и контрольные суммы находятся в `.local/upstream/SOURCE.json`. Эта копия служит материалом для аудита и последующего импорта. Она не является готовой версией MendoSave и не входит в Git. Исходник также доступен по закреплённой ссылке из [аудита](docs/SOURCE_AUDIT.md#исходная-база).

Команды запуска и проверки расширения будут добавлены после их фактического выполнения в целевом проекте. Непроверенные команды здесь не перечисляются как рабочие.

## Git и публикация

Подготовка сохраняется в локальном Git. Для последующей разработки используется отдельная task branch по `$git-conventions`. Публичный GitHub-репозиторий, его remote и каналы распространения ещё не созданы. Их создание и выпуск требуют отдельного применимого разрешения.
